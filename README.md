# A Case Study on Quantum Machine Learning

An interactive, full-screen research presentation on quantum kernel methods versus a classical SVM.

## Run locally

Requires Node.js and npm.

```sh
npm install
npm run dev
```

The app uses a 16:9 presentation canvas, keyboard arrow navigation, progressive reveals, and reduced-motion support. It contains exactly seven slides; press the right arrow or the primary control to reveal each layer and advance.
